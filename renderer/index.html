Live mode Smooth any window in real time, no file needed: video player, browser, windowed game. Uses the Interpolation model and Speed target selected below - one choice drives both file renders and live smoothing (models without a live mode fall back automatically). Click Smooth It Live!, then during the countdown click the window you want smoothed - or press ` (backtick) in any app to toggle it instantly (the key is reserved system-wide while this app runs). A green readout on the window shows source fps → smoothed fps and the delay. Windowed or borderless only; Esc (while watching), ` or Stop ends it.

Dolby Vision Opt-in. Adds Profile 8.1 dynamic-HDR metadata on top of the HDR10 render (via the open-source dovi_tool); the video stays a normal HDR10 file everywhere else. Best for TVs and devices in the Dolby Vision ecosystem: LG, Sony, most streaming boxes. Samsung TVs don't support it.
